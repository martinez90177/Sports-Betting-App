# PropPalace

## Testing on your phone

1. Start the dev server: `npm run dev`
2. Make sure your phone is on the same Wi-Fi as this PC.
3. Open this on your phone's browser:

   **http://192.168.1.177:5173**

If the IP above stops working (e.g. this PC gets a new IP from your router), run `ipconfig` in a terminal here and look for the "IPv4 Address" line, then swap it into the URL above.
